# 📰 Live News App

**Live News App** is a responsive, React-based web application that delivers real-time news headlines from multiple categories using external APIs. It offers a smooth and clean news reading experience directly in your browser.

---

## 🚀 Key Features

- 🔴 Live news fetched from an external news API  
- 📂 Categorized news (e.g., Sports, Technology, Business)  
- 📱 Fully responsive design for all screen sizes  
- ⚛️ Built with modular React components  
- 🔄 Auto-refreshing content support

---

## 🧑‍💻 Tech Stack

- **Framework:** React.js  
- **Languages:** JavaScript, HTML, CSS  
- **API:** NewsAPI or similar (API key required)  
- **Styling:** Custom CSS

---

## 📂 Key Files

| File             | Description                          |
|------------------|--------------------------------------|
| `App.js`         | Main app logic and route structure   |
| `News.js`        | Component to fetch and render news   |
| `App.css`        | Styles for the app                   |
| `index.js`       | React root rendering                 |
| `package.json`   | Project dependencies and metadata    |

---

## 🛠️ Setup Instructions

To run the project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Tushar5758/Live-News-App.git
   cd Live-News-App
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Add your API key**:
   - Sign up at [https://newsapi.org](https://newsapi.org) to get your API key.
   - Replace the placeholder key in `News.js` with your API key.

4. **Start the development server**:
   ```bash
   npm start
   ```
